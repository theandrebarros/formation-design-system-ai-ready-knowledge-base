## Component Token Naming Convention

```
--fd-colors-component-{component}-{variant}-{property}-{state}

component: button | pill | tab | data-input | selection-control | card
variant:   primary | secondary | tertiary | destructive | transparent | inverse | button-link
property:  background | border | content | label | icon | indicator | description | foreground
state:     base | hover | active | disabled | selected | error | success | unselected
```
