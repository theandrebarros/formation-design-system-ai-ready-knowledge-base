# Formation Token Pipeline

This skill's `references/` content is auto-generated by the `formation-token-pipeline`.

## Regenerating the skill

Clone the `formation-token-pipeline` repo, then run:

```bash
npm run all
```

## Pipeline structure

```
formation-token-pipeline/
├── src/generate/cursor.ts   ← generates all files in references/
├── canonical/               ← intermediate JSON (code-tokens, design-tokens, components, merged)
└── package.json             ← npm run all | gen:skill
```

Token source: `@fanduel/formation-tokens` v1.6.0 CSS files in `formation-tokens-source/`

## Note for maintainers

The `cursor.ts` generator currently outputs the old SKILL.md format (with `disable-model-invocation: true` and machine-specific paths). After running `npm run all`, manually restore the frontmatter and structure from the canonical `SKILL.md` in this directory, or update `cursor.ts` to emit the new format directly.
