How it works

One guidelines doc. Pasted once. Every prompt governed.

Formation rules — tokens, components, BU themes, fonts — live in a single guidelines.md. We paste it into the AI tool's configuration so every prompt in the file inherits the rules automatically.

6 Lovable WIP

Start from a real Figma design.

Share a Figma frame URL inside Lovable. It reads the visual structure and translates it into React code — still using Formation tokens and FD conventions from the system prompt.

What's different vs Figma Make

Lovable outputs actual React code — not Figma layers. Better for longer multi-screen flows and developer handoff. Figma Make is faster for single-screen explorations.

Formation rules stay enforced

The system prompt carries Formation guidelines into every Lovable generation — data-theme, tokens, spacing, no hardcoded hex values.
